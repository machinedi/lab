Work OS is a dashboard I run on localhost for one user: me. I wanted a place to see work without losing it in a chat scroll, and without dressing a personal tool up as software for sale.

Empty states are honest. If nothing is running, the screen says so. It does not invent activity to look alive.

Pipelines that do not need a model do not call one. A lot of useful work is a script, a file move, a checklist. Those paths stay zero-token on purpose.

Agents are optional and gated. They do not start themselves. I open the gate when I want a model in the loop, and I can see what it produced next to the step that asked for it.

This is not a SaaS. There is no team plan, no invite link, and no public demo. It is a cockpit I keep local so the work stays visible and the outputs stay attached to the step that made them.
